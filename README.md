# Laravel Project Setup Guide

This guide will help you run a Laravel project downloaded from GitHub.

## 📦 Requirements

Make sure you have the following installed:

- PHP >= 8.1
- Composer
- MySQL or PostgreSQL
- Node.js and NPM
- Laravel CLI (optional but helpful)
